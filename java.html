Java Tutorial

Learn the fundamentals of Java programming and understand the basics of object-oriented programming.

1. What is Java?

Java is a popular programming language used to build web applications, desktop applications, mobile applications and many other software systems.

Java is known for being platform-independent, which means Java programs can run on different operating systems using the Java Virtual Machine.

2. Java Program Structure

Every Java program contains a class and a main method where program execution begins. 

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World");

    }

}

3. Java Variables

Variables are used to store data values in a Java program. 

String name = "John";
int age = 20;

System.out.println(name);
System.out.println(age);

4. Java Data Types

Java provides different data types to store different types of information.

  • int - stores whole numbers
  • double - stores decimal numbers
  • char - stores a single character
  • boolean - stores true or false values
  • String - stores text
int number = 10;
double price = 99.5;
char grade = 'A';
boolean isLearning = true;
String course = "Java";

5. Java Operators

Operators are used to perform operations on variables and values. 

int a = 10;
int b = 5;

int sum = a + b;
int difference = a - b;

System.out.println(sum);
System.out.println(difference);

6. Conditional Statements

Conditional statements allow a program to make decisions based on conditions. 

int age = 18;

if (age >= 18) {

    System.out.println("You are eligible.");

} else {

    System.out.println("You are not eligible.");

}

7. Java Loops

Loops are used to repeat a block of code multiple times. 

for (int i = 1; i <= 5; i++) {

    System.out.println(i);

}

8. Java Arrays

An array is used to store multiple values of the same data type. 

String[] courses = {
    "HTML",
    "CSS",
    "Java"
};

System.out.println(courses[0]);

9. Java Methods

A method is a block of code that performs a specific task. Methods help make programs organized and reusable. 

public static void greet() {

    System.out.println("Hello!");

}

public static void main(String[] args) {

    greet();

}

10. Object-Oriented Programming

Java is an object-oriented programming language. It uses classes and objects to organize programs.

Some important object-oriented programming concepts are:

  • Classes and Objects
  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction
