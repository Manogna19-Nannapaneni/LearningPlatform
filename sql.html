SQL Tutorial

Learn the basics of SQL and understand how to store, manage and retrieve data from databases.

1. What is SQL?

SQL stands for Structured Query Language. It is used to communicate with and manage relational databases.

SQL can be used to create databases and tables, insert data, retrieve data, update records and delete records.

2. What is a Database?

A database is an organized collection of data. It helps us store and manage information efficiently. 

CREATE DATABASE learning_platform;

3. Creating a Table

Tables are used to organize data into rows and columns. 

CREATE TABLE students (
    id INT,
    name VARCHAR(50),
    age INT
);

4. Inserting Data

The INSERT INTO statement is used to add new records to a table. 

INSERT INTO students (id, name, age)
VALUES (1, 'John', 20);

5. Retrieving Data Using SELECT

The SELECT statement is used to retrieve data from a database table. 

SELECT * FROM students;

6. Using the WHERE Clause

The WHERE clause is used to filter records based on a specific condition. 

SELECT * FROM students
WHERE age >= 18;

7. Updating Data

The UPDATE statement is used to modify existing records in a table. 

UPDATE students
SET age = 21
WHERE id = 1;

8. Deleting Data

The DELETE statement is used to remove records from a table. 

DELETE FROM students
WHERE id = 1;

9. Primary Key

A primary key is used to uniquely identify each record in a table. 

CREATE TABLE courses (
    id INT PRIMARY KEY,
    course_name VARCHAR(100)
);

10. ORDER BY

The ORDER BY clause is used to sort the results returned by a query. 

SELECT * FROM students
ORDER BY name;
