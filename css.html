CSS Tutorial

Learn how to style and design web pages using CSS.

1. What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and design HTML elements.

CSS can control colors, fonts, spacing, layouts, borders and many other visual properties.

2. CSS Syntax

A CSS rule normally contains a selector and a declaration block. 

p {
    color: blue;
    font-size: 20px;
}

3. CSS Selectors

Selectors are used to select HTML elements that we want to style.

Common selectors include:

  • Element selector
  • Class selector
  • ID selector
p {
    color: red;
}

.title {
    color: blue;
}

#heading {
    color: green;
}

4. CSS Colors

CSS allows us to change the color of text and backgrounds. 

h1 {
    color: blue;
}

body {
    background-color: lightgray;
}

5. CSS Backgrounds

The background-color property is used to change the background color. 

body {
    background-color: lightblue;
}

6. CSS Fonts

CSS provides properties to control the appearance of text. 

p {
    font-family: Arial;
    font-size: 18px;
    font-weight: bold;
}

7. CSS Borders

Borders can be added around HTML elements. 

div {
    border: 2px solid black;
}

8. Margin and Padding

Margin creates space outside an element, while padding creates space inside an element. 

div {
    margin: 20px;
    padding: 20px;
}

9. CSS Box Model

Every HTML element can be considered as a box.

The CSS box model consists of:

  • Content
  • Padding
  • Border
  • Margin

10. CSS Flexbox

Flexbox is used to create flexible layouts and arrange elements in rows or columns. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
