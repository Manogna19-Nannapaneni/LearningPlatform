JavaScript Tutorial

Learn the basics of JavaScript and make your web pages interactive.

1. What is JavaScript?

JavaScript is a programming language used to make web pages interactive and dynamic.

It can be used to respond to user actions, change web page content and perform many tasks.

2. JavaScript Output

JavaScript can display output in different ways. One common method is using console.log(). 

console.log("Hello World");

3. JavaScript Variables

Variables are used to store data in a program. 

let name = "John";
const age = 20;

console.log(name);
console.log(age);

4. JavaScript Data Types

JavaScript supports different types of data.

  • String
  • Number
  • Boolean
  • Undefined
  • Object
let name = "Learning Platform";
let number = 10;
let isLearning = true;

5. JavaScript Operators

Operators are used to perform operations on values. 

let a = 10;
let b = 5;

let sum = a + b;
let difference = a - b;

console.log(sum);
console.log(difference);

6. Conditional Statements

Conditional statements are used to make decisions based on different conditions. 

let age = 18;

if (age >= 18) {
    console.log("You are eligible.");
} else {
    console.log("You are not eligible.");
}

7. JavaScript Loops

Loops are used to repeat a block of code. 

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

8. JavaScript Functions

Functions are reusable blocks of code that perform a specific task. 

function greet() {
    console.log("Hello!");
}

greet();

9. JavaScript Arrays

An array is used to store multiple values in a single variable. 

let courses = ["HTML", "CSS", "JavaScript"];

console.log(courses);

10. JavaScript and HTML

JavaScript can be used together with HTML to create interactive web pages.

JavaScript can change text, respond to button clicks and update elements on a web page.
