HTML Tutorial

Learn the basics of HTML and understand how web pages are created.

1. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure of web pages.

HTML uses elements and tags to define different parts of a web page.

2. Basic HTML Structure

Every HTML document normally contains a basic structure. 

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

</body>

</html>

3. HTML Headings

HTML provides six levels of headings, from h1 to h6. 

<h1>Main Heading</h1>
<h2>Second Heading</h2>
<h3>Third Heading</h3>

4. HTML Paragraphs

The paragraph tag is used to display a paragraph of text. 

<p>
This is a paragraph.
</p>

5. HTML Links

The anchor tag is used to create links to other pages or websites. 

<a href="https://example.com">
    Visit Website
</a>

6. HTML Images

The image tag is used to display images on a web page. 

<img src="image.jpg" alt="My Image">

7. HTML Lists

HTML supports ordered and unordered lists.

Unordered List:

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Ordered List:

<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
    <li>Build Website</li>
</ol>

8. HTML Tables

Tables are used to display information in rows and columns. 

<table>

    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>John</td>
        <td>21</td>
    </tr>

</table>

9. HTML Forms

Forms are used to collect information from users. 

<form>

    <label>Name:</label>

    <input type="text">

    <button>Submit</button>

</form>

10. Semantic HTML

Semantic elements clearly describe their meaning and purpose.

Examples:

  • header
  • nav
  • main
  • section
  • article
  • aside
  • footer
